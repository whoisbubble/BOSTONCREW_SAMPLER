# BOSTONCREW SAMPLER v1.0.2 Free

Публичный бесплатный релиз BOSTONCREW SAMPLER v1.0.2 с поддержкой управления тумбами для интерактивов!

## Что нового в v1.0.2

- 🔌 **Интерактивные тумбы (WebSocket Reset Command)**:
  - При воспроизведении самого первого сэмпла в сетке (сэмпл 0) и при выборе/переключении слайдов из списка по WebSocket передается команда:
    `NEXT_SLIDE`
  - Данная команда используется тумбами для автоматического аннулирования/сброса нажатий игроков при начале нового раунда или слайда.
- 🎵 **Автоотбивки (Auto-Jingles)**: Автоматическое воспроизведение случайных треков при правильном ответе (звук OK), включая клики из Cue-окна.
- 📜 **Менеджер слайдов**: Прокрутка списков колесиком и Drag & Drop перетаскивание слайдов и медиа.
- 🎬 **Удержание последнего кадра видео**: Бесшовная остановка без мигания.
- ⏱ **Хронометраж в пульте (Remote)**: Вывод времени воспроизведения в реальном времени.

## Полный список WebSocket-команд для тумб

- `NEXT_SLIDE` — переключение на следующий слайд / запуск 1-го сэмпла (сброс тумб).
- `RIGHT` — верный ответ (звук OK / Like).
- `WRONG` — неверный ответ (звук NO / Dislike).
- `HOST` / `HSFALSE` — служебное приветствие при подключении.
