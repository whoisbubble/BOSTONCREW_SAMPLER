# BOSTONCREW SAMPLER v1.0.3 Free

Публичный бесплатный релиз BOSTONCREW SAMPLER v1.0.3 с полноценным Проводником медиа слайдов (Slide Media Explorer) и генератором видео-тумбнейлов!

## Что нового в v1.0.3

- 🗂 **Проводник медиа слайдов (Slide Media Explorer)**:
  - Отдельное независимое окно для работы с блоками до 200+ файлов.
  - Поддержка выделения множества файлов (`Ctrl+Клик`, `Shift+Клик`, «Выделить все»).
  - Пакетные перемещения в начало, в конец, батч-удаление и вставка после выделенных карточек.
  - Интуитивный режим перемещения без лагов: **«📌 Вставить после...» (Anchor Move)** с комфортной прокруткой колесом мыши.
  - Растягивание окна во все стороны и кнопка полноэкранного режима.
  - Всплывающее меню настроек медиа по правой кнопке мыши (ПКМ).

- 🖼 **C++ Движок видео-тумбнейлов (Video Thumbnail Engine)**:
  - Автоматический асинхронный захват 1-го кадра видео в JPEG с дисковым кэшированием.
  - Проигрывание видео в плитках сетки превью заменено на легкие статичные кадры-превью.
  - Полное устранение нагрузки на GPU/декодеры в сетках превью и отсутствие фризов при перетаскивании окон.

- ⚡ **Оптимизация быстродействия и стабильности**:
  - Моментальный показ фото-слайдов при переключении с видеороликов.
  - Гарантированная защита от утечек памяти, дескрипторов и потоков при обработке медиафайлов.
