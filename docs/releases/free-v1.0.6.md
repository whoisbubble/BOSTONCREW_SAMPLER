# BOSTONCREW SAMPLER v1.0.6 Free

Публичный бесплатный релиз BOSTONCREW SAMPLER v1.0.6 с исправлениями критических багов и улучшенным интерфейсом Менеджера слайдов.

## Что нового в v1.0.6

- 🐛 **Исправление двойного звука**: Устранена проблема пугающего наложения и дублирования звуков при запуске слайдов, вызванная ошибочным воспроизведением дополнительного аудио-кью.
- 🗂 **Менеджер слайдов**:
  - Увеличен дефолтный размер окна менеджера слайдов для более удобной навигации.
  - Починено отображение миниатюр видеороликов (теперь они корректно подтягивают сгенерированные превью).
- 🖼 **Проводник медиа**:
  - Мгновенное обновление UI при добавлении новых медиафайлов. Обложки добавленных видео загружаются сразу же без перезапуска.
- 🗑 **Очистка данных**:
  - Исправлен баг, из-за которого при удалении блоков или медиафайлов они оставались на диске в папке `Content`. Теперь удаление происходит корректно и асинхронно, предотвращая захламление диска заблокированными файлами.

## Что скачать

- `BOSTONCREW-SAMPLER-windows-setup.exe` — установщик для Windows.
- `BOSTONCREW-SAMPLER-windows-portable.zip` — portable-сборка для Windows.
- `BOSTONCREW-SAMPLER-macos-x64.dmg` — сборка для Mac на процессорах Intel.
- `BOSTONCREW-SAMPLER-macos-arm64.dmg` — сборка для Mac на Apple Silicon (M1/M2/M3/M4).
